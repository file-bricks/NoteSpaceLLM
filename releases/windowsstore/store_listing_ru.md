# Карточка Microsoft Store (Русский) — NoteSpaceLLM Pro

## Название продукта
NoteSpace LLM Pro

## Краткое описание (максимум 100 символов)
Локальные заметки и анализ документов с RAG-поиском, поддержкой PDF и ИИ.

## Подробное описание
NoteSpaceLLM Pro — это ваше персональное локальное рабочее пространство для глубокого анализа документов, ведения интеллектуальных заметок и исследований с поддержкой искусственного интеллекта. Разработанный как приватная альтернатива облачным сервисам, NoteSpaceLLM сохраняет все ваши файлы, заметки и векторные индексы исключительно на локальном устройстве.

Импортируйте документы PDF, Word, файлы Markdown и текстовые заметки, используя современные технологии RAG (генерация с расширенным поиском) для ответов на контекстные вопросы по вашим материалам. Благодаря гибкой поддержке языковых моделей вы можете работать полностью автономно с локальными моделями (через Ollama) либо подключаться к защищенным облачным API.

Создавайте структурированные отчеты о глубоких исследованиях, выжимки ключевых тем и экспортируйте результаты в форматы Markdown, PDF, DOCX или HTML. Входящий в комплект автономный Web/PWA-компаньон позволяет изучать экспортированные базы знаний на смартфонах и планшетах без внешних серверов.

## Основные возможности
- Локальный анализ документов PDF, Word, Markdown и текстовых файлов
- Векторный RAG-поиск с семантической сегментацией контента
- Поддержка автономных локальных моделей и защищенных API
- Формирование структурированных исследовательских отчетов
- Экспорт в форматы Markdown, PDF, DOCX, HTML и обычный текст
- Автономный PWA-компаньон для мобильного просмотра на смартфонах и планшетах
- Полный контроль конфиденциальности: локальное хранение без передачи в облако
