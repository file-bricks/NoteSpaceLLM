# 微软商店商品信息（简体中文）— NoteSpaceLLM Pro

## 产品标题
NoteSpace LLM Pro

## 简短描述（最多100个字符）
基于本地RAG向量检索、PDF集成与AI助手的笔记与文档研究工作站。

## 详细描述
NoteSpaceLLM Pro 是您的私密本地工作空间，专为深入的文档分析、智能笔记整理和人工智能辅助研究而打造。作为传统云端笔记本服务的隐私友好型替代方案，NoteSpaceLLM 将您所有的文件、笔记和向量索引完全保存在您的本地设备上。

轻松导入 PDF、Word 文档、Markdown 笔记或纯文本，利用先进的检索增强生成（RAG）技术直接针对您的知识库提出富有上下文语境的问题。得益于灵活的模型支持，您可以借助本地模型（如 Ollama）在完全离线状态下工作，或连接到经过安全认证的云端 API 服务。

自动生成结构化深度研究报告，并将您的知识成果导出为 Markdown、PDF、DOCX 或 HTML 格式。附带的轻量级 Web/PWA 移动协同端让您无需任何外部服务器即可在平板电脑或智能手机上离线审查导出的知识库。

## 主要功能
- 支持 PDF、Word、Markdown 和文本的本地文档分析
- 具备语义切分的 RAG 向量检索与上下文问答
- 支持离线本地大模型及安全云端接口
- 自动生成结构化深度研究报告与综合摘要
- 多格式导出支持：Markdown、PDF、DOCX、HTML 与 TXT
- 离线 Web/PWA 移动协同端（支持平板与手机快速查阅）
- 本地优先与隐私安全：无需强制上传任何文件至云端
